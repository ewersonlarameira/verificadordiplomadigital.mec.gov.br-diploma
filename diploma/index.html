Verificar a estrutura XML do Diploma

Esta página de exemplo reproduz o fluxo de seleção de um arquivo XML do diploma digital. O teste é feito no seu navegador.

A demonstração verifica apenas a sintaxe do XML. Para verificar a conformidade com o XSD, use o verificador oficial do MEC.
